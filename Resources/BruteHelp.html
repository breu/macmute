Using Brute

For macOS 13 or later. This guide is bundled with Brute and works offline.

Brute lives in your Mac’s menu bar. Click its microphone icon to see the microphone state, shortcut status, and settings. Launching Brute leaves your existing microphone state unchanged.

Choose Brute Help… from the menu to open this guide. The menu also offers Preferences…, About Brute, and Quit Brute; microphone changes use the shortcut.

Tap or hold

The default shortcut is Option–Command–M (⌥⌘M).

GestureStarting unmutedStarting muted
Tap and releaseSwitches to muted and stays mutedSwitches to unmuted and stays unmuted
Hold until the delay is reachedMuted while heldUnmuted while held
Release a holdReturns to unmutedReturns to muted

A tap changes the state when you release the shortcut. A hold changes it when the delay is reached and restores the previous state when you release. Two quick taps toggle twice; there is no special double-click action.

Adjust the delay

Use the Tap–hold delay slider in the main menu. Choose 0.2, 0.4, 0.6, 0.8, or 1.0 seconds. The default is 0.4 seconds.

A press shorter than the delay is a tap. A press that reaches the delay is a hold. Your selection is saved; changes apply to the next gesture.

Which microphone is controlled?

Brute controls your Mac’s default input device. Apps using that microphone share its mute state. An app that explicitly selects a different microphone is unaffected.

For example, if your default input is a USB microphone but a calling app uses your Mac’s built-in microphone, muting the USB microphone will not mute that call. Select the same microphone in your Mac’s sound settings and the calling app.

If you change the default microphone while muted, Brute carries the mute state to the new default device.

Preferences

Open Preferences… from the menu to change the shortcut or enable Launch at Login. To change the shortcut, click its button and press a key combination with a modifier, or press fn alone. The standalone fn shortcut requires Accessibility access in System Settings → Privacy & Security → Accessibility. Preferences reports shortcut registration or Launch at Login errors.

Check the state

The menu bar icon is red when muted and green when unmuted. To use a monochrome icon that follows the system appearance, turn off Use Colored Icon in Preferences.

The menu reports whether the microphone is Muted or Unmuted. It also explains when Brute cannot verify or change the state. If no input device is available, check that your microphone is connected and selected as the default input.

If the shortcut does not respond, check the menu’s Hotkey status and any error in Preferences. If your calling app still hears audio while Brute reports Muted, check which microphone that app uses.

If macOS asks for microphone access, review Brute’s permission in System Settings → Privacy & Security → Microphone. Brute does not open an audio recording stream.

Install Brute in Applications before enabling Launch at Login so its location stays stable.

Brute does not record or transmit audio. Use Quit Brute in the menu to exit.
