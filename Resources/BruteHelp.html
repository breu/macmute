Using Brute

For macOS 13 or later. This guide is bundled with Brute and works offline.

Brute lives in your Mac’s menu bar. Click its microphone icon to see the microphone state, shortcut status, and settings. On launch, Brute reads the current microphone state and may finish a pending change or restore an interrupted hold.

Choose Brute Help… from the menu to open this guide. The menu also offers Preferences…, About Brute, and Quit Brute; microphone changes use the shortcut.

Use the shortcut

The default shortcut is Option–Command–M (⌥⌘M).

GestureStarting unmutedStarting muted
Hold for 0.2 secondsMutes while heldUnmutes while held
Release a holdReturns to unmutedReturns to muted
Tap onceStays unmutedStays muted
Tap twice quicklySwitches to muted on the second releaseSwitches to unmuted on the second release

Each tap is a press and release that lasts less than 0.2 seconds. To switch permanently, release the second tap within the double-press window.

Adjust the double-press window

Use the menu’s Double-press window slider to set the maximum time between releases. Choose 0.2, 0.4, 0.6, 0.8, or 1.0 seconds. The default is 0.4 seconds.

Which microphone is controlled?

Brute controls your Mac’s default input device. Apps using that microphone share its mute state. An app that explicitly selects a different microphone is unaffected.

For example, if your default input is a USB microphone but a calling app uses your Mac’s built-in microphone, muting the USB microphone will not mute that call. Select the same microphone in your Mac’s sound settings and the calling app.

Changing the default microphone ends an active hold and restores the original device. Outside a hold, Brute carries an active mute to the new default device.

Preferences

Open Preferences… from the menu to change the shortcut or enable Launch at Login. To change the shortcut, click its button and press a key combination with a modifier, or press fn alone. The standalone Fn shortcut requires permission in System Settings → Privacy & Security → Input Monitoring. Preferences reports shortcut registration or Launch at Login errors.

Check the state

The menu bar icon shows the microphone’s current state, including temporary changes during a hold. The colored icon is red when muted and green when unmuted. To use a monochrome icon that follows the system appearance, turn off Use Colored Icon in Preferences.

The menu reports whether the microphone is Muted or Unmuted. It also explains when Brute cannot verify or change the state. If no input device is available, check that your microphone is connected and selected as the default input.

If the shortcut does not respond, check the menu’s Hotkey status and any error in Preferences. If your calling app still hears audio while Brute reports Muted, check which microphone that app uses.

If macOS asks for microphone access, review Brute’s permission in System Settings → Privacy & Security → Microphone. Brute does not open an audio recording stream.

Install Brute in Applications before enabling Launch at Login so its location stays stable.

Brute does not record or transmit audio. Read the bundled privacy policy for details. Use Quit Brute in the menu to exit.
